Este proyecto está motivado por intereses propios. Es una especie de Letterboxd personal, orientado a la organización de distintos directores de cine y sus filmografías. Lo que me interesa a mí es organizar páginas de directores con las películas que hicieron y, espero (todavía no disponemos de las herramientas para eso), que se puedan añadir reseñas para cada película si el usuario (yo) quiera hacerlo. También me gustaría que se puedan agregar películas nuevas al proyecto.
Para poder probar los distintos contenidos del curso (que me imagino que además serán evaluados), voy a incorporar páginas para que 1. se pueda registrar un usuario nuevo, 2. Contacto (Algo pedido para la pre-entrega), y 3. Una sección de merchandising/productos.
